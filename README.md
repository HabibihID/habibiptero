# Habibiptero

Installer Pterodactyl all-in-one + tema original dari **Habibih Cloud ID**.

## Pasang installer
```bash
bash <(curl -s https://raw.githubusercontent.com/HabibihID/habibiptero/main/install.sh)
```

## Tema original (ekstensi Blueprint)
Unduh file `.blueprint` dari halaman Releases repo ini, letakkan di direktori panel, lalu:
```bash
blueprint -install habibivertex   # Habibi Vertex — navy + aksen hijau
blueprint -install habibiaurora   # Habibi Aurora — navy indigo + aksen biru
```
Atau pasang langsung dari katalog tema di dalam installer (menu 6, pilihan 9 & 10).

Sumber tema ada di folder `themes/`. Tema pihak ketiga yang gratis & open-source
tetap diunduh dari repo author masing-masing lewat katalog di installer.
